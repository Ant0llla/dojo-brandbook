# DOJO — четыре экрана ожидания

Автономная motion-страница внутри актуального `DOJO Brand & UI Kit` от 30 сентября 2026 года. Варианты используют токены, Tektur, Golos Text, точные SVG-знаки и проверенную фотографию клуба из `../brand` — без CDN, сетевых запросов, сборщика и перерисовки логотипа.

## Открыть

- `index.html` — сравнительная сетка 2 × 2
- `index.html?variant=1` — **Дыхание маски**
- `index.html?variant=2` — **12 колонн**
- `index.html?variant=3` — **Срез слова**
- `index.html?variant=4` — **Окна клуба**
- `../index.html#waiting-oni-breath` — первый вариант внутри общего каталога кита

Если браузер ограничивает локальные файлы, из папки `brandbook/dojo-zero` запустите:

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

И откройте `http://127.0.0.1:8000/motion-waiting/`.

## Направления

| Вариант | Хореография | Цикл |
| --- | --- | --- |
| Дыхание маски | Маска смещается на 3–4 px, меняет масштаб не более чем на 0,4%, мягкий блик остается внутри исходной SVG-геометрии | 12 с |
| 12 колонн | Красный 4 px сигнал проходит по модульной сетке и возвращается; заполнение не накапливается и не изображает процент | 8 с |
| Срез слова | Узкая красная секция проходит только внутри точного wordmark; остальную часть времени экран статичен | 650 мс действия раз в 8 с |
| Окна клуба | Три кадра раскрываются один раз, затем фотография сдвигается не более чем на 6 px | 14 с |

Все четыре варианта сравниваются на одной строке состояния: «Подключаемся к клубу». Ни процент, ни ETA, ни готовность по таймеру не показываются. Номер ПК, баланс, доступность, соединение и остаток сессии должны приходить от реального хоста и не запекаются в заставку.

## Доступность и runtime

- Активный одиночный экран использует `role="status"`, `aria-live="polite"` и текстовое описание состояния.
- `prefers-reduced-motion: reduce` оставляет полный статичный кадр, останавливает shimmer, сигнал, срез и параллакс.
- Запись motion-переменных ограничена 30 обновлениями в секунду и полностью прекращается при скрытой вкладке, `gaming: true` или `hostPaused: true`.
- В `offline`, `error` и `maintenance` вариант с фотографией заменяет ее нейтральной панелью.
- Aqua появляется только в подтвержденном состоянии `ready`; остальные состояния используют фирменный red.

Минимальный контракт хоста:

```js
DojoWaiting.setState('preparing');
DojoWaiting.setState('offline');
DojoWaiting.setState('ready'); // только после подтверждения реального хоста
DojoWaiting.configure({ gaming: true });
DojoWaiting.configure({ gaming: false, hostPaused: false });
```

Допустимые состояния: `preparing`, `offline`, `ready`, `maintenance`, `error`.

## Проверка

```powershell
node --check .\motion-waiting\app.js
node .\motion-waiting\qa\run.cjs
python .\package-delivery.py --check
```

QA проверяет четыре варианта на 1920 × 1080, 1366 × 768 и 2560 × 1440, отсутствие внешних запросов и переполнения, статичный reduced-motion, паузу hidden/gaming и готовит PNG/WebP-постеры с контактным листом.
