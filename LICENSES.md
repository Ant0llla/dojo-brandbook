# Источники и условия использования

DOJO сохраняет права на свои фирменные материалы
Комплект не дает отдельную лицензию на сторонние торговые марки и игровые образы

| Материал | Статус |
| --- | --- |
| Tektur | SIL Open Font License 1.1, текст в assets/tektur-ofl.txt |
| Golos Text | SIL Open Font License 1.1, текст в assets/golos-OFL.txt |
| Edo SZ | Бесплатное коммерческое применение по условиям Vic Fieger, сведения в assets/lettering/edo-sz/LICENSING.txt, это не OFL |
| Логотипы DOJO | Фирменные исходники DOJO, технические варианты и сборки |
| Кистевой образец | Предоставленный растровый образец, не производственный вектор |
| Персонажи и fashion-art | Сгенерированные иллюстрации, не официальный игровой арт издателей |
| Фотографии клуба | Материалы DOJO, отобранные оригиналы с кадрированием в макетах, сведения в photos/provenance.json |
| Фото друзей за консолью | RDNE Stock project, Pexels, атрибуция в photos/people/provenance.json |
| Иконки программ | Идентификация соответствующих приложений, источники в ASSET-SOURCES.json |
| Batman Arkham City | Адаптация канонической обложки из каталога клуба, отдельная лицензия на игровой арт не приложена |
| Упаковки трех товаров | Изображения со страниц продавцов, источники в product/assets/product-image-sources.json, отдельная лицензия на перепубликацию не приложена |

[Pexels License](https://www.pexels.com/license/) допускает применение фото в дизайне, запрещает приписывать изображенным людям одобрение продукта и перепродавать неизмененные снимки как самостоятельный сток
Фото включено как зависимость композиции, а не отдельная библиотека стока

[Условия Vic Fieger](https://vicfieger.com/~font/faq.html) изложены в приложенной записи лицензии Edo SZ
Файл шрифта нельзя продавать как самостоятельный товар

Третьи лица сохраняют права на свои товарные знаки, персонажей и упаковки
Публикация кита не означает передачу этих прав
