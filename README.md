# DOJO Brand & UI kit

Публичная версия брендбука и продуктового UI kit DOJO

[Открыть кит](https://ant0llla.github.io/dojo-brandbook/) · [Скачать материалы](https://ant0llla.github.io/dojo-brandbook/downloads.html)

70 макетов, брендовые правила, логотипы, типографика, компоненты, игровые карточки, мерч, фото, прайсы и карты двух клубов

- `index.html` — поиск и просмотр всех макетов
- `DOJO-Brandbook.pdf` — брендбук на 70 страницах
- `cards/exports` — 81 прозрачная PNG-карточка, 600 × 900
- `cards/cards.html` и `cards/templates.html` — композиции и шаблоны карточек
- `brand`, `components`, `product`, `photos` — исходные HTML, CSS, SVG и изображения
- `ASSET-SOURCES.json` и `LICENSES.md` — происхождение и условия использования материалов

Скачанный полный комплект открывается через `index.html` без установки программ
Ссылки на скачивание ведут на GitHub Releases

Это дизайн-система и демонстрационные прототипы
Они не подключены к рабочей SmartShell, не меняют конфигурацию клуба и не показывают текущую доступность мест
Цены в примерах — снимок от 29 сентября 2026 года

Логотип DOJO и сторонние игровые образы не распространяются как общедоступная библиотека брендов
Условия сторонних материалов перечислены отдельно
